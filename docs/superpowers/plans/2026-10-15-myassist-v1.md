# MyAssist v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows desktop companion with an original movable character and offline hold-to-talk dictation into the app that was focused when recording began.

**Architecture:** Electron + TypeScript shell, Three.js character renderer, a small Python/Win32 hotkey worker packaged with PyInstaller, local whisper.cpp transcription, and guarded Unicode insertion. Audio and transcripts stay in memory unless the user copies fallback text.

**Tech Stack:** Node.js 22, Electron, Electron Forge, TypeScript, Three.js, @pixiv/three-vrm, Python 3.11, faster-whisper/CTranslate2 CPU int8, PyInstaller.
